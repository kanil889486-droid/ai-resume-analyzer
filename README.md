# 🤖 AI Resume Analyzer

An AI-based Resume Analyzer built using **Python, Flask, and NLP techniques**.  
The application allows users to upload a PDF resume and analyzes it to identify skills, calculate a resume score, suggest improvements, and recommend a suitable job role.

## 🚀 Live Demo

🔗 https://ai-resume-analyzer-qpm7.onrender.com

> Note: The free Render instance may take some time to start after inactivity.

---

## 📌 Features

- 📄 Upload resume in PDF format
- 🔍 Extract text from PDF resumes
- 🧠 Detect technical skills
- 📊 Calculate resume score
- 💼 Recommend a suitable job role
- 💡 Provide resume improvement suggestions
- 🌐 Flask web application
- ☁️ Deployed on Render
